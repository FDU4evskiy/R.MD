# Изменения в 0.1.0

**Пример заметок о выпуске** · Учёт оборудования · 13 октября 2026

## Добавлено

- Реестр оборудования с пагинацией по 50 записей.
- Создание и изменение карточки: номер, модель, категория, место хранения.
- Проверка уникальности инвентарного номера при сохранении.
- Категории «Ноутбук», «Монитор» и «Док-станция».

## Исправлено

| Ошибка                                      | Результат                                    |
| ------------------------------------------- | -------------------------------------------- |
| Пробелы в начале номера создавали дубликаты | Номер очищается до проверки                  |
| Пустая дата закупки вызывала ошибку         | Необязательное поле принимает `null`         |
| Длинная модель перекрывала соседний столбец | Текст обрезается, полное значение в карточке |

## Миграция

Создаются таблицы `equipment` и `employees`. На поле `assetTag` добавляется уникальный индекс. Справочники категорий и статусов заполняются при первом запуске.

После миграции создайте тестовую карточку и проверьте, что повторное сохранение того же номера отклоняется.

## Известное ограничение

Выдача, история операций и CSV ещё не доступны. Порядок следующих изменений — в [плане этапов](02-roadmap.md).
