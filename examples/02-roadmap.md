# Этапы MVP

**Пример плана** · Учёт оборудования · Октябрь 2026

Каждый этап заканчивается проверкой на тестовом наборе из 30 единиц оборудования и 10 сотрудников. Набор не содержит реальных персональных данных.

## План работ

| Срок          | Результат         | Проверка                 |
| ------------- | ----------------- | ------------------------ |
| 12–16 октября | Реестр и карточка | Поиск по номеру и модели |
| 19–23 октября | Выдача и возврат  | Запрет повторной выдачи  |
| 26–30 октября | История и CSV     | Экспорт с учётом фильтра |

## Реестр и карточка

- [x] Схема `equipment` и уникальный индекс номера.
- [x] Список с пагинацией по 50 записей.
- [ ] Фильтры по категории и статусу.
- [ ] Валидация серийного номера при сохранении.

## Выдача и возврат

API проверяет текущий статус внутри транзакции. Из двух одновременных запросов на выдачу проходит один; второй получает `409 equipment_unavailable`.

Проверка: создать оборудование, выдать сотруднику, повторить выдачу, вернуть и выдать ещё раз. В истории должны остаться две выдачи и один возврат.

## История и экспорт

CSV использует UTF-8 с BOM и разделитель `;`. Порядок столбцов: номер, категория, модель, статус, сотрудник, местоположение. Текстовые значения экранируются по правилам CSV.

После MVP: импорт CSV с предварительным просмотром ошибок. Требования к полям — в [спецификации](01-project.md).
