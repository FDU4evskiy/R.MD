# Интерфейс реестра

**Пример спецификации интерфейса** · Учёт оборудования

Основной экран — таблица оборудования. Над ней расположены поиск, фильтр статуса и кнопка создания карточки.

## Токены

| Назначение      | Значение        | Применение          |
| --------------- | --------------- | ------------------- |
| Основной текст  | `#24282D`       | Заголовки, значения |
| Вторичный текст | `#626A73`       | Подписи полей       |
| Действие        | `#197D62`       | Кнопки и ссылки     |
| Граница         | `#E6E9EC`       | Таблица, поля ввода |
| Отступы         | 4, 8, 16, 24 px | Сетка интерфейса    |

## Таблица

Столбцы: инвентарный номер, модель, статус, сотрудник, местоположение. Номер закреплён слева при горизонтальной прокрутке. Высота строки — 44 px; выбор строки открывает карточку.

Статус обозначается текстом и цветной точкой: **доступно**, **выдано**, **списано**. Цвет не заменяет подпись.

## Форма выдачи

- Сотрудник: поиск по справочнику, обязательное поле.
- Дата выдачи: сегодняшняя дата по умолчанию, можно изменить.
- Кнопка сохранения отключена, пока запрос выполняется.
- Ошибка отображается рядом с полем или над кнопками формы.

## Небольшие экраны

При ширине менее 768 px таблица показывает номер, модель и статус. Остальные поля доступны в карточке. Фильтры переносятся на вторую строку без горизонтальной прокрутки страницы.
