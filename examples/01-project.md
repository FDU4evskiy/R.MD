# Учёт оборудования

**Пример спецификации** · MVP · Октябрь 2026

Приложение хранит список ноутбуков, мониторов и док-станций. Для каждой единицы техники можно посмотреть местоположение, назначенного сотрудника и историю выдач.

## Состав первой версии

| Раздел   | Данные                    | Действия            |
| -------- | ------------------------- | ------------------- |
| Реестр   | Номер, модель, статус     | Поиск, фильтр, CSV  |
| Карточка | Серийный номер, закупка   | Создание, изменение |
| Выдача   | Сотрудник, дата, операция | Выдать, вернуть     |

> Инвентарный номер уникален и не меняется при передаче техники другому сотруднику.

## Правила выдачи

1. Выдавать можно только оборудование со статусом `available`.
2. Сотрудник выбирается из справочника; свободный ввод имени запрещён.
3. При выдаче статус меняется на `assigned`, запись появляется в истории.
4. Возврат закрывает выдачу и переводит оборудование в `available`.
